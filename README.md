# 🌌 Acerca del proyecto

**Vue Store-Front Template** es una plantilla de comercio electrónico desarrollada para crear tiendas online modernas utilizando el ecosistema de Vue.js.

El proyecto incluye:

- 🛒 Catálogo de productos
- 📦 Gestión visual de productos
- 🔍 Navegación dinámica
- 🧭 Sistema de rutas
- ⚡ Estado global con Vuex
- 🎨 Diseño responsive
- 🛍️ Interfaz moderna para e-commerce
- 📱 Compatibilidad móvil

# ⚡ Instalación

## 📋 Requisitos

- Node.js
- NPM
- Vue CLI
- VS Code

---

# 🚀 Configuración del proyecto

## 1️⃣ Clonar repositorio

```bash
git clone https://github.com/usuario/Vue-Ecom.git
```

---

## 2️⃣ Entrar al proyecto

```bash
cd Vue-Ecom
```

---

## 3️⃣ Instalar dependencias

```bash
npm install
```

---

## 4️⃣ Ejecutar en desarrollo

```bash
npm run serve
```

Abrir navegador en:

```bash
http://localhost:8080
```

---

## 5️⃣ Compilar para producción

```bash
npm run build
```
